# 📚 StudyBuddy — AI-Powered Study Companion

**StudyBuddy** is a modern, responsive student productivity dashboard designed to help students organize their studies, manage tasks, track progress, take notes, and stay focused.

The project is built using **HTML, CSS, and Vanilla JavaScript** and works completely in the browser without requiring a backend or API key.

---

## ✨ Features

### 🏠 Dashboard
- Personalized welcome screen
- Today's date
- Study statistics
- Overall progress
- Today's tasks
- Quick actions
- Motivational messages

### ✅ Task Manager
- Add and delete tasks
- Mark tasks as completed
- Set subjects and priorities
- Add due dates
- Filter pending and completed tasks
- Automatic progress calculation

### 📖 Subject Management
- Track multiple subjects
- View subject-wise progress
- Add new subjects
- Monitor completed tasks

### ⏱️ Study Timer
- 25-minute Pomodoro study sessions
- 5-minute break sessions
- Start, pause, and reset controls
- Study session tracking
- Automatic study-hour calculation

### 🤖 AI Study Buddy
An offline, lightweight study assistant that can respond to common study-related questions.

It can help with:
- Programming concepts
- Study tips
- Simple explanations
- Quiz questions
- Time-management suggestions
- Motivation

> **Note:** The current version uses a rule-based JavaScript assistant and does not connect to an external AI API.

### 📝 Notes
- Create notes
- Edit notes
- Delete notes
- Search notes
- Save notes automatically using browser storage

### 📊 Progress Tracking
Track:
- Completed tasks
- Pending tasks
- Study sessions
- Study hours
- Overall completion
- Daily study goals
- Current study streak

### 🌙 Dark Mode
Switch between light and dark themes for a comfortable study experience.

### 💾 Local Storage
Your tasks, notes, subjects, settings, and study data are saved using the browser's `localStorage`.

No database or account is required.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/ai-study-buddy.git
```

### 2. Open the project

Navigate into the project folder:

```bash
cd ai-study-buddy
```

### 3. Run the application

Simply open:

```text
index.html
```

in any modern web browser.

That's it! No installation or server is required.
